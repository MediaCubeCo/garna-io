# Modal Cal.com — Webflow Code Component

## Описание

Компонент **Modal Cal.com** реализует пользовательский сценарий:

**Кнопка → модальное окно → форма → встроенный календарь Cal.com**

Компонент предназначен для использования в **Webflow Code Components**  
и позволяет настраивать контент, Cal.com ссылку и внешний вид календаря  
без изменения исходного кода.

---

## Использование в Webflow

1. Добавьте **Code Component** на страницу.
2. Выберите компонент **“Modal cal.com”**.
3. Настройте параметры в правой панели Webflow.

Дополнительные скрипты на страницу добавлять не требуется.

---

## Технические детали

- Календарь Cal.com встраивается через **inline embed**.
- Данные пользователя передаются в Cal.com:
  - Full Name → `config.name`
  - Work Email → `config.email`
- Стилизация выполняется через **официальные CSS variables (`--cal-*`)**.
- Cal.com инициализируется **лениво**, только при открытии модального окна.

---

## Ограничения Cal.com

- ❌ Нет нативного fullscreen-режима
- ❌ Нет полной документации по всем `--cal-*` переменным
- ❌ Нельзя полностью изменить DOM-структуру iframe

Все кастомизации выполняются в рамках официального API Cal.com.
