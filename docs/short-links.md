# Короткие ссылки `/s/<slug>`

Навигация: [README](../README.md) · [AGENTS.md](../AGENTS.md).

Все короткие ссылки Garna живут в едином пространстве `/s/`. Это небольшой механизм редиректов внутри существующего Cloudflare Worker. Единственный источник соответствий — [src/config/short-links.ts](../src/config/short-links.ts). Проверять занятые имена и добавлять новые ссылки нужно там.

## Как добавить ссылку

1. Выбери уникальный понятный slug: строчные латинские буквы, цифры и одиночные дефисы между словами, например `career-game-5`. Проверь, что такого ключа ещё нет в реестре.
2. Добавь запись в `shortLinks`. Значение — полный путь страницы внутри сайта, включая язык и все необходимые параметры:

   ```ts
   'career-game-5': '/ru/podcast-offer?utm_source=bolshaya_karernaya_igra&utm_medium=podcast&utm_campaign=lopatina_ep5',
   ```

3. Проверь конечную страницу и UTM, добавь сценарий в [test/short-links.spec.ts](../test/short-links.spec.ts), запусти `npx vitest run test/short-links.spec.ts test/index.spec.ts` и `npm run check`.
4. Опубликуй обычным процессом проекта (`npm run deploy`), затем проверь реальный ответ: `curl -I https://garna.io/s/career-game-5`. Ожидаются `302` и `Location` с целевой страницей и точными UTM. Также открой ссылку в браузере и проверь конечную страницу.

Новая запись требует публикации Worker. Создавать страницу Astro, добавлять путь в `src/config/pages.ts` или отдельное правило Cloudflare для каждого slug не требуется. Не переиспользуй опубликованный slug для другой кампании: старые описания выпусков продолжат вести по нему.

## Поведение

- Публичный формат: `https://garna.io/s/<slug>`, без языкового префикса. Язык задаётся в целевом пути и не зависит от страны или языка браузера.
- Обработчик: [src/routes/short-links.ts](../src/routes/short-links.ts), подключён в [src/index.ts](../src/index.ts) до статических файлов и локализованной маршрутизации.
- `GET` и `HEAD` возвращают `302` с `Cache-Control: no-store`, чтобы можно было исправлять назначение без закреплённого в браузере постоянного редиректа. Остальные методы для известных ссылок — `405`.
- Источник параметров — только запись в реестре. Query-параметры короткой ссылки игнорируются, в том числе попытки заменить UTM или передать `url=...`.
- Неизвестные и некорректные адреса в `/s/` возвращают `404`. Регистр значим. Повторные слеши нормализуются внутри обработчика; `/s/career-game-1/` и `//s/career-game-1` также ведут сразу на назначение.
- Целевые пути должны начинаться с одного `/`, вести на конкретную конечную страницу сайта и не ссылаться на `/s/`, чтобы не создавать цепочки и циклы. Внешние назначения текущему механизму не нужны.
- Origin берётся из запроса: локальная и preview-проверка остаются на соответствующем окружении.
- В `wrangler.toml` пространство `/s` и `/s/*` включено в `assets.run_worker_first` для production и preview, чтобы статические файлы не перехватывали эти адреса. При добавлении slug этот список менять не нужно. [Правила Cloudflare](https://developers.cloudflare.com/workers/static-assets/routing/worker-script/).

## Подкаст «Большая карьерная игра»

Все четыре ссылки ведут на `/ru/podcast-offer` с `utm_source=bolshaya_karernaya_igra` и `utm_medium=podcast`:

| Короткий путь | `utm_campaign` |
| --- | --- |
| `/s/career-game-1` | `lopatina_ep1` |
| `/s/career-game-2` | `lopatina_ep2` |
| `/s/career-game-3` | `lopatina_ep3` |
| `/s/career-game-4` | `lopatina_ep4` |
