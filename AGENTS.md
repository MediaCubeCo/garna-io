# Garna.io

- Стек и команды проекта: [README.md](README.md). Сайт собирается Astro и обслуживается Cloudflare Worker (`src/index.ts`); конфигурация — `wrangler.toml`.
- Все новые сокращённые ссылки создавай только в пространстве `/s/<slug>`. Реестр — `src/config/short-links.ts`; правила, примеры и проверка — [docs/short-links.md](docs/short-links.md).
- Перед добавлением редиректа прочитай инструкцию и проверь существующие slug в реестре. Не создавай отдельные страницы Astro для коротких ссылок.
